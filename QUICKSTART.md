# Quick Start Guide 🚀

## Installation (One Time)

### Windows:
1. Open Command Prompt in the app folder
2. Run: `pip install -r requirements.txt`
3. Done!

### Mac/Linux:
1. Open Terminal in the app folder
2. Run: `pip install -r requirements.txt`
3. Done!

---

## Running the App

### Windows:
Double-click `run.bat`

### Mac/Linux:
1. Open Terminal in the app folder
2. Run: `./run.sh`

**App opens at:** `http://localhost:8501`

---

## Using the App

### Create a Presentation:
1. Click **"Create Presentation"** in the sidebar
2. Enter a title (e.g., "My Presentation")
3. Set number of slides
4. Fill in each slide's title and content
5. Click **"Save Presentation"**

### View a Presentation:
1. Click **"View Presentations"** in the sidebar
2. Select your presentation from dropdown
3. Use slider to navigate slides
4. Click **"Export to PowerPoint"** to save as .pptx

### Edit a Presentation:
1. Click **"Edit Presentation"** in the sidebar
2. Select presentation to edit
3. Change titles/content
4. Click **"Save Changes"**

---

## That's It!
- Presentations save automatically in `presentations/` folder
- Export to PowerPoint anytime
- No internet needed, everything local
